# Content plan (written 27 Nov 2026, nothing here is published yet)

Rules for every new page: one search intent per page, never a second page for an intent an existing page already owns,
facts only from the product and the site copy (docs/PRODUCT_FACTS.md), no invented numbers, no pages made in bulk for
near-identical queries (Google's spam policies cover its AI answers too). Each new post links to its feature page, one
free tool and the store through the existing ExtensionCta.
